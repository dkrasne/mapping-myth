This is a set of tutorials for learning QGIS, developed for the Barnard course Mapping Myth (CLCV BC3002). 
They can be used outside of this course by anyone who is interested in working with QGIS in the domain of Greek mythology.

## List of Tutorials

1. Acquiring, adding, and selecting data
1. Print layout and aesthetics
1. Refining and extending data
1. Contour lines and working with rasters
1. Sizing/clustering and binning points
1. Creating and editing data
1. Spatial joins and visualizing numeric data
