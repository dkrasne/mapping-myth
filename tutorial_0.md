# Installing QGIS

1. Visit [the QGIS website](https://www.qgis.org/) and click on the download link.

1. Make sure that your system is selected in the dropdown menu (e.g., if you use Windows, make sure it says 'Windows - Desktop OS' or if you use a Macintosh, make sure it says 'macOS - Apple Desktop').

1. Use the download link under **'Long Term Release'**, *not* under 'Latest Release.'

1. Install the program.

1. Run the program to make sure that it opens correctly on your computer.


### N.B. If you use a Macintosh:

After installation, when you try to run the program, you may get a message that says '"QGIS" cannot be opened because the developer cannot be verified.'

If this occurs, try the following:
1. In the applications folder, right click (or ctrl-click) on the QGIS icon.
2. Select “Open” from the menu options.
3. This should trigger a new warning popup that now includes the option to open QGIS anyway.
4. Select “Open” to continue the launch of QGIS.
5. You will only need to do this once. Selecting “Open” modifies the security settings for your Mac to allow future launches of QGIS to proceed without the security warning. The next time you double-click on the QGIS icon, the software will simply open up.

If the above doesn't work, try following the instructions [in this video](https://youtu.be/05FHCieaovw?si=oCAoTbhtR4dmXNNI&t=180).
